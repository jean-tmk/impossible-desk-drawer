# The Impossible Desk Drawer

A surreal, interactive desk drawer whose interior refuses to match its exterior.

Open the drawer, drag every object out of place, inspect the artifacts, and keep descending until the furniture becomes recursive.

## Live experience

[Open the Impossible Desk Drawer](https://jean-tmk.github.io/impossible-desk-drawer/)

## Interaction

- Pull the handle to open the first compartment.
- Click an object to inspect it.
- Drag all three objects to reveal the route deeper.
- Continue through stationery, private weather, and the unauthorized night shift.
- Sound can be toggled from the header.

Built as a dependency-free static web experience with semantic HTML, responsive CSS, and vanilla JavaScript.
